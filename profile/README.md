# SciLM.ai

**The AI model that can see science.**

SciLM.ai (Scientific Language Model) generates scientific simulation data at a scale no experiment can reach, and is building a multimodal foundation model that reads and writes scientific data in its native form: atoms as 3D geometry, reservoirs as 3D volumes.

Website: https://www.scilm.ai · Datasets and models: https://huggingface.co/SciLM · Contact: ilgar@scilm.ai

## Open engines

- [SaddleMill](https://github.com/SciLM-ai/SaddleMill) (MIT): high-throughput transition-state dataset generation for inorganic materials.
- [ResMill](https://github.com/SciLM-ai/ResMill) (MIT): rule-based 3D geological reservoir modeling.
- [PotMill](https://github.com/SciLM-ai/PotMill) (BSD-3): automated ML interatomic potential generation, from data generation to the final model in under one day.

## Models

- [SaddleFlow](https://github.com/SciLM-ai/SaddleFlow): generative model for transition states in inorganic materials.
- [ResFlow](https://github.com/SciLM-ai/ResFlow): flow-matching model for siliciclastic reservoirs, conditioned on wells, assembling fields of any size.

## Datasets (CC-BY 4.0)

- [MaterialsSaddles](https://huggingface.co/datasets/SciLM/MaterialsSaddles): 32.0 M reactions, 96.1 M structures.
- [SiliciclasticReservoirs](https://huggingface.co/datasets/SciLM/SiliciclasticReservoirs): 1,000,000 3D reservoir models across eight depositional architectures.
